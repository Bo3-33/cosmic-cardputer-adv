# Firmware history

All builds are development releases. Archived files are preserved as originally
built; their validation notes and limitations remain part of each kit.

| Version | Changes | Archive |
| --- | --- | --- |
| v0.7 | USB/BLE keyboard and mouse, simultaneous typing/gyro, tilt/arrow fallback; 2.25 MB launcher partition | Full image and kit |
| v0.6 | Encrypted standalone Authenticator; direct read-only Proton sync after PC pairing | Full image and kit |
| v0.5 | GB/GBC emulator with USB DualShock 4 controls, including Honeywell fan app | Full image and kit |
| v0.4 | Honeywell HYF290B raw IR remote | No separate binary was archived; included in v0.5 |
| v0.3 | LG webOS and Roku Wi-Fi remotes | Full image and kit |
| v0.2.1 | Saved-theme reload fix and connected/disconnected Wi-Fi icon | Full image and kit |
| v0.2 | Buffered display, themed WebUI, icon app list, hosted Lua apps, switcher and MP3/WAV Cover Flow player | Full image and kit |
| v0.1 | Initial COSMIC launcher, theme, Lua packages and controller bridge development | Original kit (original unversioned filename) |

Git tags import the source saved inside each archived kit. They are reconstructed
release snapshots, not the original development commit history. Kit files and
their SHA-256 checksums are attached to each GitHub release. No missing historical
binary has been fabricated. Personal full-flash backups are not firmware releases.
